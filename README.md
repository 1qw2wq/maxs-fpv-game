# 堑壕前线 · Trench Front

一战战场风格的浏览器 FPS，结合二次元角色、团队战斗与可选 AI 对手。支持单机练习、好友联机、第一／第三人称视角，以及中文／English 界面。

**无需安装客户端，无生产构建步骤。** 可直接部署在 Vercel 等静态托管平台，对局由浏览器内的 Python／Pyodide 引擎运行；也可自建 Python 服务端。

[English guide](README.en.md)

## 游戏内容

- **两种规则**：团队死斗先达 75 击杀获胜，或 8 分钟结束时比较分数；据点控制需要占领全部 A／B／C 并连续守住 15 秒。
- **三张地图**：索姆河无人区的战壕、意大利小镇的街巷，以及拥有连体建筑、可进入楼层和中央小公园的程序化旧城。
- **四个兵种、30 把武器**：26 把兵种主武器，另选 APX Carry、G17、沙漠之鹰或信号枪作为副武器；主副武器弹药独立。
- **投掷物与防护**：破片、燃烧、烟雾、闪光和黄色毒气手榴弹；防毒面具密封后阻止毒气伤害，但不会消除烟雾遮蔽。
- **可选机器人**：0–16 名 AI，提供混合、简单、普通、困难、专家难度；多人 AI 数量与难度由房主决定。
- **桌面与手机操作**：桌面使用原生鼠标锁定；独立手机模式提供摇杆、透明圆角按钮、全屏与横竖屏分别保存的自定义布局。

| 兵种 | 作战定位 | 专属技能 |
| --- | --- | --- |
| 突击兵 | 近距离进攻 | 烟雾弹，遮断视线 |
| 医疗兵 | 中距离作战与恢复 | 医疗箱，治疗附近队友 |
| 支援兵 | 火力压制 | 弹药箱，补充备用弹药 |
| 侦察兵 | 远距离侦察 | 信号弹，标记敌人；烟雾可阻挡侦察 |

## 开始游戏

1. 打开游戏网页，输入昵称；右上角可切换中文／English。
2. 选择**单机**或**多人**，设置地图、规则与 AI。第一次玩可先进入**新手指引**。
3. 选择兵种、角色、主武器和副武器，再部署；多人客人使用下方的准备流程。
4. 桌面点击画面取得鼠标锁定；手机选择手机模式，使用摇杆与按钮。阵亡后可重新选择装备并部署。

首次载入需要下载引擎和模型，较大的地图可能需要等待。若嵌入式预览无法锁定鼠标，请在独立浏览器标签页打开；手机模式不是桌面鼠标锁定失败的替代方案。

## 操作

下表为默认键位，可在 **设置 → 键盘按键布局** 中修改主按键和备用按键；立即生效并在本地保存。[自定义键位说明](docs/keyboard-layout.md)。

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 鼠标 | 移动 / 转动视角 |
| 左键 / 右键 | 开火 / 瞄准 |
| `Shift` / `Space` | 冲刺 / 跳跃 |
| `C` / `Ctrl` | 蹲下 |
| `1` / `2` | 直接选择主武器 / 副武器（支持数字小键盘） |
| `X` / `R` | 切换主副武器 / 换弹 |
| `Q` | 兵种技能；烟雾弹与信号弹可按住蓄力、松开投掷 |
| `B` / 按住、松开 `G` | 选择手榴弹类型 / 蓄力、投掷 |
| `M` | 佩戴或取下防毒面具；需要 0.75 秒密封 |
| `V` | 切换第一／第三人称 |
| `Tab` / `Enter` | 查看战绩 / 聊天 |
| `Esc` | 释放鼠标并打开暂停菜单 |

手机使用对应屏幕按钮，持续推动摇杆 1.5 秒进入冲刺。可在暂停菜单调整按钮布局。

## 与朋友联机

**房间流程**：房主创建房间，在主页面接受加入申请并设置地图与规则。获准客人会自动进入角色选择，选好装备后点**准备**。房主选择自己的装备，再点**开始游戏**，所有已准备玩家自动进入同一局。

- **同一浏览器的多个标签页**：使用房号或房间链接；需要相同网站来源和浏览器存储分区，普通窗口与无痕窗口不能混用。
- **不同浏览器／设备**：使用**邀请朋友**交换邀请码与回答码，完成 WebRTC 配对，再由房主接受申请。每位朋友需要单独配对。
- **自建 Python 服务端**：朋友可打开服务端打印的局域网地址，在同一服务端加入房间；设备之间需能访问该地址。

静态托管不需要常驻后端或消息代理，**房主必须保持页面运行**。跨设备能否直连取决于网络；可选 STUN 不能保证跨 NAT 成功，严格防火墙或对称 NAT 可能需要 TURN，而 Vercel 本身不提供 TURN。

## 运行与部署

### Vercel 纯静态部署

1. 导入仓库，**Framework Preset** 选择 **Other**。
2. **Root Directory** 设为 `public`，使用其中的 `vercel.json`；Build Command 与 Output Directory 留空。
3. 部署后打开网址即可玩单机或浏览器房主联机。无需 npm、打包或额外游戏后端。

### 本地运行／可选服务端

需要 **Python 3.10+**：

```sh
pip install -r requirements.txt
python server/server.py --open
```

打开终端打印的网址（默认 `http://127.0.0.1:8080`）；同一局域网的朋友使用打印的 LAN 地址。Windows 也可双击 [`启动服务器.bat`](启动服务器.bat)。按 `Ctrl+C` 停止。

可选容器部署见 [`Dockerfile`](Dockerfile)，Render 部署配置见 [`render.yaml`](render.yaml)。自建服务端还支持共享上传角色；纯静态托管不提供上传存储服务。
