**关键技术决策**
- **单端口**：aiohttp 一个 8080 端口同时提供静态文件与 `/ws`。`/ws` 路由必须**先于** `add_static('/')` 注册；加中间件强制 `Cache-Control: no-store`（避免改了 JSON 浏览器不刷新）。
- **无构建**：原生 ES Module + import map（`{"imports":{"three":"./vendor/three.module.js"}}`，必须写在任何 module script 之前）。three.js 版本锁 **0.169.0**，只下 `build/three.module.js` 一个文件，用 `curl.exe`（PS 5.1 下 `Invoke-WebRequest` 慢且会弹 IE 首启）。
- **Windows 细节**：不用 `loop.add_signal_handler`（Windows 抛 `NotImplementedError`），用 `try/except KeyboardInterrupt`；**服务端日志只用 ASCII**（GBK 控制台遇中文会崩）；路径统一 `Path(__file__).parent`，不依赖 CWD；默认绑 `127.0.0.1`（绑 0.0.0.0 会弹防火墙，局域网联机时再切）；8080 被占则自动顺延并打印真实 URL。

## 二、游戏设计

### 兵种与武器（12 把）

字段最小集：`{id, class, name, dmg, rpm, mag, reloadMs, spreadDeg, rangeM, falloff, zoomFov, auto, lethalBody}`。**每兵种只管 3 个低模武器外观 + 换色**，不单独建模。

| 兵种 | 定位 | 武器（3 把） | 职业特性 / Q 技能 |
|---|---|---|---|
| **突击兵** | 近距爆发 | MP18 伯格曼（550rpm/32发）、M1918 自动步枪（900rpm/25发）、赫利格尔 M1915（550rpm/60发弹鼓） | 移速最快；**炸药包**：抛物线投掷，范围爆炸伤害 |
| **医疗兵** | 中距续航 | 塞-里戈蒂（半自动 300rpm/10发）、蒙德拉贡 M1908（260rpm/10发/高伤）、塞尔布斯特拉德尔 M1916（260rpm/20发） | **医疗包**：范围内治疗自己与队友；可救援濒死队友 |
| **支援兵** | 压制火力 | 刘易斯机枪（500rpm/47发弹盘）、BAR M1918（500rpm/20发）、MG15 n.A.（600rpm/100发弹链） | **弹药箱**：范围内补给弹药；命中即**压制**敌人（加大其散布/画面边缘模糊） |
| **侦察兵** | 远程狙击 | 李-恩菲尔德 SMLE MkIII（拉栓快）、毛瑟 Gewehr 98（弹道直/初速高）、斯普林菲尔德 M1903（最高伤） | 高倍镜；**有效射程内躯干一枪致命**；**信号弹**：标记区域敌人供全队可见 |

**伤害模型**：基础 HP 100。部位倍率 头 ×2.0 / 躯干 ×1.0 / 四肢 ×0.8；伤害随距离在 `rangeM` 后线性衰减至 `falloff`。侦察兵栓动枪额外带 `lethalBody`（躯干致死窗口）。

### 角色设定：4 名二次元美少女（核心美术）

**比例**：半写实二次元 **约 5.5~6 头身**（参考《少女前线》《尘白禁区》），站高按 **1.70m** 走（保证地图尺度与判头手感正常），但**身形纤细**、头部略大于写实。**不采用 Q 版 2~3 头身**——FPS 里过矮会毁掉射击判定与距离感。

| 兵种 | 少女设定 | 发型 | 主色 | 一战 × 二次元服装 | 剪影可辨识点 |
|---|---|---|---|---|---|
| **突击兵** | 元气冲锋系，热血小队长 | 齐耳短发 + 侧发卡 | 橙红 | 卡其短风衣、战术短裙、长靴、亚德里安钢盔（斜戴） | 最娇小、背炸药包、动作最快 |
| **医疗兵** | 温柔治愈系，队内大和抚子 | 长卷发 + 侧编辫 + 白发带 | 白粉 | 白色护士风军装、红十字臂章、斜挎药箱、及膝靴 | 药箱 + 红十字 | 
| **支援兵** | 沉稳大姐系，扛得住 | 高马尾 + 厚刘海 | 黄绿 | 重型军大衣披肩、交叉弹药带、工装长裤、军帽 | 最宽肩背、满身弹链 |
| **侦察兵** | 冷静神秘系，寡言狙击手 | 长直发 + 微遮刘海 + 贝雷帽 | 蓝紫 | 长风衣半披、高筒袜、望远镜挂饰、软帽 | 最细长、长枪、披风飘动 |

**统一要素**：大眼睛 + 小嘴 + 腮红的标准二次元五官；卡通描边；**头发高光带**（anime hair highlight，二次元感的关键）；战斗手套与护具保持"打仗的样子"，不做纯装饰萌系。

**阵营区分（避免敌我误判）**
- 协约国：蓝白臂章 + 青蓝色**发光轮廓**
- 同盟国：红黑臂章 + 橙红色**发光轮廓**
- **队友额外显示**：头顶青蓝小三角标记 + 光晕（敌人不显示，防止破坏竞技性）

**第一人称表现**：玩家能看到自己的**少女双臂 + 战斗手套**（袖口/手套取兵种主色），左右手分离持枪，换弹有独立动画。

**工程注意**：头部判定盒以**颅骨**为准（不吃头发的体积，否则双马尾会变成"免费大靶子"）；长发/披风/弹链做**刚体摆动或骨骼微动**，不做物理模拟。

### 地图：索姆河无人区（约 120m × 80m）
- 中央无人区：弹坑、铁丝网、枯树、混凝土碉堡
- 两侧对称堑壕系统：沙袋胸墙、木栈道、掩体、机枪巢
- 两端各 3 个出生点（分属协约国 / 同盟国）
- `map.json` 内以 AABB 数组描述，**服务端用于命中判定、客户端用于生成网格与碰撞**，坐标约定统一写入文件（three.js Y-up 右手系）。

### 玩法
- 团队死斗：两队自动平衡，**先达 75 击杀**或 **8 分钟**结算，高分队获胜
- 死亡后 3 秒在己方出生点重生，期间可换兵种/武器
- 操作：WASD 移动 / Shift 冲刺 / Ctrl 蹲 / Space 跳 / 左键开火 / 右键 ADS / R 换弹 / Q 技能 / Tab 记分板
- HUD：血量、弹药、动态准星、命中标记、击杀提示流、记分板；**不做小地图**（见下方削减清单）

### 联机与单机可玩性
- 真联机：多人连同一 `ws://` 地址即成局
- **可选 AI 机器人**（默认关闭，菜单可开）：仅用于单人时能看到一局真正在跑的对抗，便于演示与自测

## 三、网络模型（核心风险点）

采用 **客户端权威移动 + 服务端权威命中**（不用纯服务端移动，否则延迟手感会很差）：

1. **服务端唯一权威**：只接受客户端的移动上报与"我朝这个方向开了一枪"，**永不接受客户端上报的伤害/击杀**。
2. **射速服务端强制**：每把武器有最小开火间隔，超频请求直接丢弃（客户端 RPM 仅作表现）。
3. **移动钳制**：服务端限制每 tick 最大位移、拒绝穿墙坐标，超限拉回。
4. **命中判定**：`ray vs capsule(半径 0.3)`（比 ray vs AABB 手感更宽容），含距离衰减与部位倍率。
5. **延迟补偿（先简后繁）**：
   - 一期（必做）：客户端远端玩家固定 **120ms 插值延迟** + **判定胶囊放大到 0.25~0.35m**，即可解决绝大多数"我看着打中了却没中"。
   - 二期（跑通后再加）：服务端维护每玩家约 1s 位置环形缓冲，收到 `fire` 时回滚到 `serverNow - interpDelay` 判定。

**协议（JSON over WS）**
- C→S：`join{name,class,weapon}`、`input{pos,rot,state}`、`fire{origin,dir,weapon,seq}`、`reload`、`ability{type,pos,dir}`、`respawn{class,weapon}`、`chat`
- S→C：`welcome{id,tickRate,map}`、`state{players[],effects[]}`（20Hz）、`hit{...}`、`kill{killer,victim,weapon,head}`、`scores{...}`、`respawn{pos}`、`notice`

## 四、二次元美术实现

- **卡通材质**：`MeshToonMaterial` + `gradientMap`（`DataTexture` + `NearestFilter`，**必须给**，否则就是平涂）。不使用 PBR 参数（MeshToonMaterial 不支持 metalness/roughness）。
- **描边（二次元的灵魂）**：倒壳法——复制网格、`side: THREE.BackSide`、整体放大 1.03 倍、深色材质。**只对闭合网格使用**（开放面会漏）。描边色 = 兵种主色或阵营色。
- **美少女角色构建**（`character.js` + `face.js`）：
  - **骨架式拼装**：躯干/上臂/前臂/大腿/小腿/头/发 分组挂到 Group，行走摆臂与呼吸起伏用**正弦驱动关节旋转**（不做物理、不做蒙皮，成本最低且足够好看）。
  - **头部**：略大的颅骨球体 + 下巴收窄，比例向二次元靠拢；**头发**用低多边形挤出条带组成，含 4 种发型（短发/长卷/高马尾/长直），**必带头发高光带**（沿头顶一圈亮色环，二次元辨识度最高的特征）。
  - **面部**：`face.js` 用 Canvas 2D 程序化绘制贴图——眼白 + 虹膜渐变 + 高光点 + 睫毛 + 眉毛 + 小嘴 + 腮红，贴到头部前侧网格。**不依赖任何外部素材**，离线可用。
  - **服装**：风衣/短裙/长靴/手套/臂章用几何体块拼装，主色取自兵种配色；钢盔、贝雷帽、药箱、弹药带、披风作为兵种标识配件。
- **光照与影子**：**不开实时阴影**，用脚下一个深色圆片当假阴影；饱和暖调方向光 + 冷调环境光模拟战壕黄昏；加一条**边缘光（rim light）**让少女轮廓从背景中跳出来。
- **UI**：渐变描边面板、粗体描边字、兵种立绘、击杀提示动效，整体走二次元游戏 UI 语言（圆角、高饱和、半透明磨砂）。
- **立绘**：setup 阶段用文生图把 4 张**二次元美少女兵种立绘**下载到 `public/assets/portraits/`，用于主菜单与兵种选择界面。**必须做降级**——下载失败则回退为纯 CSS 渐变头像 + 兵种图标，避免离线开天窗。

## 七、验证方式

1. **启动**：`python server/server.py`（`cwd` 设为项目根目录）→ 确认打印监听 URL 且无异常。
2. **服务端自检**：`python -c "import json,pathlib;..."` 校验 `shared/*.json` 可被 Python 与 JSON 双方解析。
3. **单机冒烟（浏览器子代理）**：打开 `http://127.0.0.1:8080`，验证主菜单渲染 → 选兵种/武器 → 进入地图 → 指针锁定 → 移动/开火/换弹 → HUD 数值变化。**必须截图确认角色是二次元美少女**：能看出眼睛/发型/头发高光/描边，且 4 兵种一眼可区分、敌我轮廓色不同。
4. **联机验证**：同时开 2 个浏览器标签/上下文连接同一地址，验证互相可见、**远端少女角色身形与动画正常**、移动平滑（插值生效）、射击能互相造成伤害与击杀、记分板与击杀提示正确、可复活。
5. **机器人验证（可选）**：开启 bot 补位，确认单人也能跑完整一局并正常结算。
